古韵今风 - 古诗词大模型

作品主旨

习近平总书记指出，传统文化的传承不仅要保护和弘扬经典，还要与现代文明相结合，实现文化的创造性转化和创新性发展。 本团队旨在将大模型技术和古诗词文化相结合，训练出一个精通古诗词的“专家”模型。通过用户交互平台，让用户能直观、有效地学习和创作诗句，弘扬中华传统文化。

系统介绍

主界面

主界面包含“赏诗”和“作诗”两个主要按钮，分别跳转到相应的功能界面，右侧的介绍按钮跳转到信息页面。

智绘古诗界面

用户可通过左侧3D动态云选择诗句，或直接输入诗句，右侧上方输出框展示生成结果。

智写新诗界面

用户输入题目，选择对应风格后生成诗句，输出框左侧显示诗句，右侧显示对应图片。

技术实现

数据集

使用 Kaggle 的《Classic Chinese Poem with annotation》及 Github 的《Chinese-poetry》数据集，数据包括古诗、翻译和解析。

模型训练

我们训练了 2 个 llama3-Chinese-8B 模型和 1 个 Stable-Diffusion 模型，分别用于文字生成和图像生成。

微调前后效果对比展示了模型在诗句生成和图像生成方面的提升。

总结与展望

通过 AI 技术与传统文化的结合，实现文化的传承和技术创新。未来希望进一步优化模型训练方法和数据集，提升生成效果。
